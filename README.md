# 🆕 New work, new commits — November 2026

### 🔬 I removed 75% of what a vision model sees. It still answers correctly. Why?

I reproduced an experiment from [arXiv 2605.22903](https://arxiv.org/abs/2605.22903) on an 8 GB Apple M1.
I removed up to 75% of the image tokens of Qwen3-VL-4B. POPE accuracy went from 91.3% to only 87.3%.

### 👉 [See the result and how I got it](https://ashe-many.github.io/vlm-token-drop/)

The page shows the result, the diagrams and the checks. It links to the code and the paper.
